# Tossed_book

Here I tried to translate in Python the original Matlab codes written by Alyssa Novelia and revised by Daniel Kawano that can be found here: https://rotations.berkeley.edu/wp-content/uploads/2017/12/tossed_book.txt and described in details here https://rotations.berkeley.edu/simulations/

Please if you use it, remember to cite both the original work and then my (if you use the python code).
