# Doppler_experiment

The code here is inspired to the work of Di Laccio, Juan L., Leonardo Núñez, and Salvador Gil (2021). “A low-cost laboratory experiment to simulate Doppler spectroscopy of binary stars and exoplanets”. In: The Physics Teacher 59.6, pp. 412–417. 

The set up that is the acoustic translation of the method used to discover binaries, because simulates the acoustic equivalent of the "radial velocity method" in astronomy.

Please remember to cite both the original paper and this code page if you use them.
